# Tela Inicial - Menu de Seleção

## Descrição

A primeira tela do sistema exibe um menu com duas opções principais:

1. **Dashboard Administrativo** — Acesso ao painel de gerenciamento do torneio (cadastro de atletas, chaves, categorias, confrontos, etc.).
2. **Placar** — Exibição do placar ao vivo para a arena/ público.

## Layout (proposto)

```
================================
   BJJ TOURNAMENT MANAGER
================================

   [1] Dashboard Administrativo
   [2] Placar

   Escolha uma opção: _
================================
```

## Comportamento

- O usuário seleciona a opção desejada (teclado / clique).
- Ao selecionar **Dashboard Administrativo**, o sistema redireciona para a tela de login ou diretamente para o painel admin (a definir).
- Ao selecionar **Placar**, o sistema redireciona para a tela de placar ao vivo.

## Observações

- O menu deve ser responsivo e de fácil leitura em dispositivos usados na arena (tablets, TVs, notebooks).
- As opções podem ser acionadas por toque, mouse ou teclado numérico.
